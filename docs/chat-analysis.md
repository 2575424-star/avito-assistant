# Анализ чатов и сверка с выводами GPT

24.09.2026. Выгрузка сервиса: 1100 чатов (первые 1100 по списку Авито), 2155 сообщений, 23.01–24.09.2026. Входящие — первым написал клиент и есть живой текст: 216 чатов, из них 209 с ответом продавца и без телефона до ответа. Звонков в выгрузке нет (только отметки «[Звонок]»); звонки будут загружены из API CPA/calltracking на этапе 1. Имена сотрудников и данные клиентов в этом файле не приводятся.

Все цифры — наблюдения, не эксперимент: связь не доказывает причину. Выборки в подгруппах малы.

## Что подтверждается (совпадает с GPT)

- Конверсия входящих в телефон: **47 из 216 (21,8%)**, у GPT 48 из 206 (23,3%). Разница — в исключениях и распознавании номера.
- Просьба контакта: **32,8% с просьбой против 2,6% без неё** (у GPT 33,8% против 5,3%).
- Разброс по менеджерам совпадает с GPT с точностью до 1–2 чатов; лучшие отличаются тем, что просят контакт почти в каждом чате.

## Новое, чего нет у GPT

1. **Главная потеря — клиент молчит после первого ответа: 39% входящих.** После неудачной первой просьбы номера в 59 из 90 случаев клиент больше не ответил; прямых отказов «пишите сюда» — единицы.
2. **Скорость первого ответа** (связь сильная): ответ до 5 минут — 33% телефонов, 5–30 минут — 25%, 30 минут–2 часа — 17%, позже — 17%. При ответе до 30 минут клиент продолжает разговор в 69% чатов, позже — в 55%. Медиана первого ответа продавцов — 32–75 минут. Агент отвечает за секунды и ночью — это его главное преимущество.
3. **Просьба контакта уже в первом ответе:** 33% телефонов против 11%, хотя отвечают на такой первый ответ реже (55% против 66%). Данные ближе к стратегии A (ранний шаг), чем к B.
4. **Когда клиент даёт номер:** обычно во 2-й своей реплике (29 случаев) или в 3-й (14). Дальше — единицы.
5. **Цена цифрой в ответе на вопрос о цене:** 1 из 13 оставили телефон, без суммы — 13 из 55. Выборка мала и смещена, вывод делать нельзя; это гипотеза для проверки, а не повод скрывать цену.
6. **Бюджет Авито:** около 40 из ~97 вероятно платных чатов стали платными из-за 5 реплик без телефона (см. [avito-cpa-rules.md](avito-cpa-rules.md)). **Повторное сообщение продавца без ответа клиента новую реплику не создаёт** (реплика — подряд идущие сообщения одного собеседника), поэтому одно напоминание молчащему клиенту не делает чат платным, если в нём нет адреса, ссылок, контактов и фото.

## Что по формулировкам просьбы

Первая просьба номера срабатывала в 31% случаев. Простое «оставьте номер, менеджер перезвонит» — 36% (92 случая); с обещанием расчёта/подбора — 19% (31); с обещанием видео/фото — 3 из 4. Подгруппы малы, «польза» в формулировке пока не доказана. Проверять в эксперименте, а не закладывать как правило.

## Оценка материалов GPT (v0.1.0)

Согласен: порядок «ответ по существу → следующий шаг → контакт», запрет выдумывать цены и наличие, история как данные, а не истина, честный ответ про ИИ, передача человеку, отдельные проверочные ситуации, план эксперимента, когортная конверсия, осторожность с шаблонами исходящих.

Нужно исправить:

1. **Противоречие в роли.** Раздел «Роль и цель» называет агента «виртуальным помощником», а решение владельца — «Ярослав, менеджер отдела продаж». Оставить представление Ярославом, честный ответ на прямой вопрос об ИИ.
2. **R15 «Бюджет» устарел:** писался без правил. Теперь правила известны — заменить конкретикой: что делает чат платным, «не отговаривать звонить» (п. 2.9), оплата один раз на чат.
3. **Инструкция длинная (~25 тыс. знаков) и рассчитана на инструменты** (CRM, запись, назначение сотрудника), которых у агента нет. Для gpt-4o-mini лучше короткая версия под наш формат JSON: у агента есть только ответ, телефон, передача менеджеру и «промолчать».
4. **«Один вопрос в конце каждого ответа» (R03) и стратегия B добавляют реплики:** по правилам Авито это ведёт к оплате без телефона. Первое сравнение: A против C, B — позже. Сравнивать и по конверсии, и по стоимости обращения.
5. **Нет напоминания молчащему клиенту** для входящих чатов, а это главная потеря. Предлагаю одно напоминание через 2–4 часа — как отдельную проверяемую гипотезу, после этапа 1, только в тестовом режиме до решения владельца.
6. **Скорость** у GPT — операционный показатель; по данным это один из самых сильных факторов. Задержку ответа агента держать короткой (15–60 секунд), без искусственных пауз.

Инструкция с этими поправками: [agent-prompt-v0.2.0.md](agent-prompt-v0.2.0.md).
