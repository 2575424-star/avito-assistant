# Avito Assistant — вводная для нового участника (человека или ИИ-ассистента)

Прочитай целиком, затем `AGENTS.md` (обязательные правила) и `docs/WORKLOG.md` (журнал, решения, кто что делает). Секретов в репозитории нет и быть не должно.

## 1. Что это

ИИ-менеджер для чатов Авито автосалона Павла (кабинет **InDrive Воронеж**, новые автомобили). Отвечает покупателям от имени «Ярослава, менеджера отдела продаж», цель — полезный ответ и телефон клиента для менеджера. Позже — интеграция с **VECTOR CRM** (отдельный репозиторий `2575424-star/VECTOR-CRM`).

Сейчас **тестовый режим**: агент пишет черновики, в Авито ничего не отправляется. Идёт выбор стратегии общения и модели в «Лаборатории».

## 2. Кто работает

- **Павел** — владелец: задачи, решения, секреты, доступы.
- **ChatGPT/Codex** — анализ переписок, общий слой правил агента, стратегии `codex_business` и `codex_friendly`, учебные материалы. Ветки `gpt/…` или пакеты материалов.
- **Claude Code** — код сервиса, интеграции, «Лаборатория», стратегия `claude_independent`, анализ данных. Ветки `claude/…`.

## 3. Разделы интерфейса

| Раздел | Что делает |
|---|---|
| Дашборд | контакты, когортная конверсия (телефон за 7 дней), работа бота |
| Чаты | переписки из Авито, черновики ИИ пунктиром, оценка 👍/👎, «Прогнать ИИ», «Разбор» |
| Успешные чаты | лиды с телефоном, CSV |
| Архив и аналитика | загрузка всей истории, статистика продавцов, выгрузка JSONL, **расходы Авито (CPA)**, разбор чатов нейросетью |
| База знаний | факты, FAQ, возражения, примеры (кандидаты → утверждено); автомобили из API и фида, наличие «в наличии / в пути» |
| Проверка ответов | прогон агента по реальным чатам, сравнение с ответами продавцов |
| **Лаборатория** | 3 стратегии × 2 модели (GPT-6 Sol / Luna) на тестовых вопросах, оценки, стоимость, слепая оценка, экспорт |
| Настройки | Агент (тестовый/боевой режим), Стратегии (версии промптов), **Ключи и модели** (профили ключей OpenAI), Шаблоны, Авито, Уведомления, Журнал событий |

## 4. Устройство кода

Node.js 22 без внешних зависимостей: встроенные `http`, `node:sqlite`, `fetch`. Интерфейс — `public/app.js` без сборки.

| Файл | Что |
|---|---|
| `src/server.js` | HTTP-сервер и все `/api/...` |
| `src/db.js` | схема SQLite, миграции колонок, настройки |
| `src/avito.js` | клиент API Авито (мессенджер, объявления, автозагрузка, CPA) + запрет отправки в тестовом режиме |
| `src/engine.js` | синхронизация чатов, черновики/автоответ, лиды |
| `src/agent.js` | промпт живого агента (правила или версия стратегии + карточка авто + база знаний), вызов OpenAI |
| `src/chatstate.js` | распознавание телефона, направление чата, **оценка платности чата по правилам Авито**, строка «СОСТОЯНИЕ ЧАТА» |
| `src/knowledge.js` | база знаний, автомобили, фид, наличие |
| `src/history.js` | загрузка истории, когортная статистика, прогоны по чатам, разбор нейросетью |
| `src/billing.js` | фактические списания Авито (CPA), отчёт, кандидаты на опротестование |
| `src/lab.js`, `src/llm.js` | «Лаборатория»: сборка промпта, прогоны, автопроверки, стоимость; вызов OpenAI (Responses/Chat) по профилям ключей |
| `src/lab/*.md` | общий слой правил и тексты стратегий (засеваются в таблицу `agent_versions`) |
| `src/lab/*_questions.jsonl` | тестовые сценарии: 12 стандартных (Codex) и 20 частых вопросов (Claude, обезличено) |
| `test/mock-server.js`, `test/smoke.js` | мок Авито/OpenAI и сквозной тест: `npm test` |

Как собирается промпт агента: общий слой → одна стратегия → карточка автомобиля и факты → «СОСТОЯНИЕ ЧАТА» (реплики, платность) → адаптер формата JSON `{reply, phone, handoff, skip}` → история чата.

## 5. Сервер и деплой

- Railway: проект **Avito Assistant**, сервис **avito-assistant**, окружение production, домен https://avito-ai-platon.up.railway.app, том `/data` (SQLite).
- **Автодеплой из `main`**: слияние PR → сборка по `Dockerfile` (копирует `src/` и `public/`) → проверить статус и логи.
- Переменные Railway: `ADMIN_PASSWORD`, `DATA_DIR=/data`, `PORT`. Ключи Авито и OpenAI Павел вводит в интерфейсе, они в базе на томе. Ключи моделей «Лаборатории» — Настройки → Ключи и модели (отдельный проект OpenAI на модель).
- Локально: `ADMIN_PASSWORD=x npm start`; на моках: `npm run mock` + переменные `AVITO_API_BASE`, `OPENAI_BASE_URL` (см. README).
